# Storyfeed README artwork

The banner uses the approved refreshing activity queue: nine compact motifs, 3-second holds and .75-second advances. GIFs are 1600×428 pixels displayed at 800×214, with a stationary, vertically centered outlined Instrument Sans wordmark and no tagline. PNG/SVG alternatives show the exact complete selected07 still; the README picture chooses the light static PNG for reduced motion in either theme. A standalone reduced-motion source comes first because GitHub rewrites theme-containing conditions. Both light and dark static downloads remain available here. README derivatives use #FFFFFF light and #0d1117 dark backgrounds, with exact gold, orange and teal preserved in the GIF palette. The original kit banners are unchanged.

Editable renderer, font/OFL, source hashes, capture script, manifests and the complete kit live in [storyfeed/docs brand/current](https://github.com/storyfeed/docs/tree/main/brand/current). No JavaScript runs inside the GitHub README. The GIF is a browser capture of the actual approved renderer, not an SVG claiming executable animation. GitHub Markdown API preserves the media source; hosted repository/Camo behaviour requires post-push verification.
